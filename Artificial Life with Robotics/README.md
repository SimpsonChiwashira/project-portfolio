# Artificial Life with Robotics

## Overview
This project explores artificial life concepts and robotics through simulation and modeling. The coursework includes agent-based modeling and autonomous vehicle simulation.

## Project Components

### 1. Agent Based Modelling - Infectious Diseases
- **File**: `Agent Based Modelling - Infectious Diseases.nlogo`
- **Tool**: NetLogo
- **Description**: Simulation of infectious disease spread using agent-based modeling
- **Status**: Implementation complete, documentation pending

### 2. Self-Driving Vehicle with Object Detection and Avoidance
- **Folder**: `A-Life - CW2 - v2/`
- **File**: `Self Driving Vehicle with object detection and avoidance - Unity.txt`
- **Tool**: Unity
- **Description**: Autonomous vehicle simulation with object detection and avoidance capabilities
- **Status**: Code implementation added to lecturer-provided Unity project
- **Note**: Unity project folder now included

## Technology Stack
- **NetLogo**: Agent-based modeling and simulation
- **Unity**: Game engine for robotics simulation
- **C#**: Programming language for Unity scripts

## Installation & Setup

### NetLogo
1. Download and install NetLogo from [https://ccl.northwestern.edu/netlogo/](https://ccl.northwestern.edu/netlogo/)
2. Open the `.nlogo` file in NetLogo
3. Run the simulation using the NetLogo interface

### Unity
1. Install Unity Hub and appropriate Unity version
2. Open the Unity project (project file to be added)
3. Navigate to the self-driving vehicle scene
4. Run the simulation

## Project Details

### Infectious Disease Simulation
- Agent-based modeling approach
- Simulates disease spread through population
- Parameters for infection rate, recovery time, etc.
- Visualization of disease dynamics

### Self-Driving Vehicle
- Object detection using sensors
- Avoidance algorithms for obstacle navigation
- Autonomous navigation in simulated environment
- Real-time decision making
