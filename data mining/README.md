# Data Mining Coursework

## Overview
This project implements text classification and analysis using data mining techniques. The coursework focuses on document classification using machine learning algorithms.

## Project Files
- **Report.docx** - Detailed project report documenting methodology and results
- **Results.xlsx** - Classification results and performance metrics
- **file1.arff** - Original dataset in ARFF format
- **stemmed.arff** - Preprocessed dataset with stemming applied
- **non-stemmed.arff** - Preprocessed dataset without stemming

## Methodology
1. **Data Preprocessing**: Text cleaning and normalization
2. **Feature Extraction**: Converting text to numerical features
3. **Classification**: Applied machine learning algorithms for document categorization
4. **Evaluation**: Performance analysis using standard metrics

## Dataset
The original dataset was provided as part of the 7COM1018 Data Mining module coursework. The dataset contains business and technology documents that were classified into categories.

## Results
Classification results and performance metrics are documented in the Results.xlsx file and detailed analysis is provided in the project report.

## Tools & Technologies
- Data mining and machine learning techniques
- ARFF file format for data representation
- Text preprocessing (stemming vs non-stemming approaches)

## Academic Context
This project was completed as part of a Data Mining module, focusing on practical application of classification algorithms to real-world text data.
